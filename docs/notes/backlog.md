## Decisions
- **Per-competition accuracy is public on the how-it-works pages** (Yarin's fix206 request, 23 Oct 2026): competition, games (last 365 days), main-pick hit rate and Brier score, only competitions with 20+ finished games (the 10 Oct worry about small samples). The Accuracy pages themselves stay admin-only; the "See the full record" link on the how-it-works pages shows for admins only.
- **Every competition counts in the public record** (Yarin, 23 Oct 2026, fix203): no "in testing" exclusion in any sport (football TRIAL_COMPETITIONS, basketball BB_TRIAL removed, env vars TRIAL_COMPETITIONS / BB_TRIAL_LEAGUES ignored). "In testing" is only an admin label in Admin → Football / Basketball leagues, with no effect on any number. Pre-season basketball stays out (not real games); tennis ITF stays admin-only.
- **Israel = a normal league** (Yarin, 19 Oct 2026): no special hiding, no highlighting. Ligat Ha'al (AF383) gets news and predictions like every league (added through Admin → Football leagues; nothing in the code blocks AF383 from its own v3 group). The Israeli basketball league is not added (ask Yarin first). CLAUDE.md rule replaced (fix192).
- **Every game gets a prediction** (Yarin, 20 Oct 2026, fix192): a team new to a league starts from a newcomer prior; admin data health lists every game of the next 7 days (all sports) without one, with the reason — target zero.
- **Our recommended pick = double chance** (decision 17 Oct, Yarin): subscribers get the double chance (1X / X2 / 12, the two most likely results, % = their sum) as the recommended pick, football only. The three 1X2 percentages stay as they are. "Strong pick" = double chance 85%+, shown only as a small extra label. A settled pick counts as right when the result is inside the double chance; the 1X2 result is still tracked as "the hard calls" (admin + Accuracy page). Basketball unchanged (no draws). One rule in `backend/src/utils/doubleChance.ts` and `frontend/src/lib/predict.ts` (ties go 1X, X2, 12).
